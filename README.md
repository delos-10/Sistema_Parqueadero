# Sistema_Parqueadero
# ParkZone

Aplicación web para la gestión de parqueaderos. Permite administrar espacios de parqueo, roles de usuario (administrador y operador), reservas de espacios con seguimiento de ocupación, y registro de entrada y salida de vehículos, incluyendo validación de placas colombianas y cobro por minuto.

## Cómo instalar y ejecutar localmente

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/delos-10/Sistema_Parqueadero.git
   ```
2. Entrar a la carpeta del proyecto:
   ```bash
   cd Sistema_Parqueadero
   ```
3. Abrir el archivo `index.html` en el navegador. Como el proyecto es HTML, CSS y JavaScript puro (no necesita instalación de dependencias ni build), también puedes usar una extensión como **Live Server** de VS Code para ejecutarlo con recarga automática.
